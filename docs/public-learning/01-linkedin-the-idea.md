# LinkedIn: the idea

Most savings groups in East Africa still run on a notebook and a WhatsApp thread.

So for my final project I'm building ChamaLedger, a ledger for chamas: contributions, loans and portfolio at risk.

The feature I care about most is boring on purpose: a payment recorded twice is impossible. Each one is tied to its mobile-money reference, so a retry on a bad connection stays safe.

Spec first, code second. Every requirement has acceptance criteria before a line is written.

Code and tracker: https://github.com/devotuoma/chamaledger
