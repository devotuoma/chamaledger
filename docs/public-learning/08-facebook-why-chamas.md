# Facebook: why chamas

If you've ever been part of a chama, you know how it goes. Someone says "I paid", the notebook says otherwise, and now it's awkward.

I built ChamaLedger as my final project to help with that. It records each contribution by its mobile-money reference, so the same payment can't be counted twice. It also shows how much lending is overdue, before it becomes a crisis.

It's a demo for now, not for real money yet, but the code is free for anyone to read: https://github.com/devotuoma/chamaledger
